# Sourav Banerjee | Portfolio Website

This repository contains the source code for my personal portfolio website, built with plain HTML, CSS, and JavaScript. The site showcases my background as a Junior Machine Learning Engineer, highlights selected projects, shares my writing, and provides links to my social profiles.

## Overview

The website is designed to be simple, clean, and easy to navigate. It includes:

- A homepage introducing who I am
- An About Me page with my journey, experience, and education
- A Projects page that displays selected GitHub repositories
- A Blogs page for published content and ideas
- A Socials page with links to my online presence

## Project Structure

- index.html — Home page
- pages/about.html — About section
- pages/blogs.html — Blog listings
- pages/projects.html — Project showcase
- pages/socials.html — Social links
- style.css — Main stylesheet
- assets/ — Images and site assets

## Features

- Responsive navigation for desktop and mobile
- Clean, minimal portfolio design
- Dynamic project cards fetched from GitHub
- SEO-friendly metadata for social sharing
- Easy to host on GitHub Pages

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome icons
- GitHub API for project data
